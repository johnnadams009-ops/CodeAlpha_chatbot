# 🤖 AI Assistant

A general-purpose AI chatbot built with Python, Google Gemini API, and Streamlit.

The application can answer general questions, maintain conversation context, assist with writing and brainstorming, and retrieve current information using Google Search grounding.

## 🌟 Features

- 🤖 General-purpose AI assistant
- 💬 Interactive chatbot interface
- 🧠 Conversation context and follow-up questions
- 🔎 Google Search grounding for current information
- 📰 Current news and recent events
- 📈 Current trends and developments
- 💡 Project ideas and brainstorming
- ✍️ Writing and content assistance
- 🗑️ Clear Chat functionality
- 💡 Suggested questions
- 🌐 Streamlit web interface
- 🔐 Secure API key management
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google Search Grounding
- Streamlit
- python-dotenv
- Git
- GitHub
